最後更新：2026-10-12

本檔是小鎮**當前進度、下一步與文件索引的單一事實來源**。這是好玩的小專案，文件保持輕量：完成條件見 `docs/P2/實作規格.md`，怎麼做見 `docs/P2/開發設計方針.md`，怎麼驗見 `docs/P2/測試指南.md`（P1 的三份在 `docs/P1/`）。

## 專案定位與目前能力

Three.js 做的迷你小鎮網頁（純靜態，無建置、無後端），素材全部是 Kenney CC0。執行：`start.bat`（python http.server，`http://localhost:8766/`）。部署：Cloudflare Pages，Build output directory = `small-town`。

已交付：

- 時間流動與晝夜（清晨／中午／黃昏／夜晚，倍速與暫停）。
- 居民依作息上下班、回家；路人、散步者、公園長椅、公車與乘客。
- 散步模式（P）：WASD 走、Shift 跑、空白鍵跳、E 互動；換裝（C）與取名。
- 找貓（8 隻）與噴水池許願（10 個祝福）。
- 編輯模式（B）：搬動／旋轉／刪除建築與路燈、新增住家／別墅／商店／樹／路燈、在固定地圖範圍內鋪馬路／人行道／斑馬線、undo、10 格含俯視快照存檔、帶關卡的匯出／匯入 json。
- 網格道路與自動人行道、通用行人找路、小鎮關卡資料化；找貓／祝福／投幣紀錄依關卡保存。
- 車流走路網：靠右、路口獨佔、死路迴轉、斑馬線停讓；公車大街西行停站。

## 已拍板的決定

- 地圖做法 **B**：每關一份自己的地圖資料，**街道結構可以完全不同**（十字、T 字、彎道、死路皆可）。
- 街道一律是鋪路網格上的馬路格，人行道自動生成；汽車與行人的路線都由網格推出，不寫死某條街。
- 每關有固定的地圖範圍，也就是可編輯範圍；汽車只從範圍邊緣進出。第 1 關兩條街直接畫到範圍邊緣（霧外），原本的「延長兩條街」功能移除。
- 行人嚴格優先走斑馬線，完全沒有路線時才直接穿越；編輯造成到不了時，該段留在原地，公車不發車，路通後恢復。
- 目前進度（關卡＋佈局）存在同一個 key，一次寫完；換關寫入失敗時原進度不變。
- 第 1 關的後街從 z=-7.2 移到 **z=-8.0**（對齊網格）；舊存檔自動遷移：後街區域（z < -3.6）的建築與路燈往北移 0.8，該區的鋪路格與舊的街道延長段清掉，其餘照搬。
- 貓與許願**綁定關卡**；某關可以沒有許願或沒有貓。找貓、祝福收集與投幣紀錄依關卡分開保存，舊紀錄歸第 1 關。
- 火車站關卡的居民用**不具名簡化版**（通勤客在車站與建築間往返，沒有作息表）。
- 火車只放第 2 關「火車站」，第 1 關不加鐵道；P1-C 先用第二關草稿驗證系統，正式車站配置與通勤客留待 P1-D。
- 存檔名稱自動為「關卡名＋時間」，附地圖中央快照；存檔格數 **10**。
- 進網站直接接續上次進度，時間從早上 06:00 開始；換關或存讀進度按「關卡與存檔」，再選「開始新小鎮」或「存檔／讀檔」。
- 舊的 3 格存檔、自動存檔、找貓紀錄自動歸到第 1 關。
- P1 預估超過原訂的一兩天（A1／A2 合計約一天），已接受。
- P2（2026-10-12 拍板）：經營模式只做第 2 關；資金單位「萬」、起始 5,000 萬、寬鬆經濟（不破產，負數只禁購）加「無限資金」開關，每天 06:00 結算一次、與倍速無關；火車是一台一台買、可命名，五種車型，整點班表（每小時每方向最多一班，每班選車、方向、停或不停），開完停在那一頭、下一趟只能反向；預設車隊普通 2 台＋雙層特急 1 台與預設班表；公車只決定台數（上限 4）、可選色；鋪路要錢；住宅沿路自動成長（可開關、可清隨機樹、不碰玩家種的樹），商店也自動長但控制比例，公寓升級只限車站附近或商店密集處、別墅不升級；倍速改 1×／10×／60×，火車汽車行人一起跟著加速，60× 用略過模式。

## 跨 Subphase 約束

- 輕量優先：不做通用關卡編輯器、不做建置流程。
- 每個 Subphase 在自己的分支 `feat/small-town-<subphase 小寫>` 上做，驗證完、使用者同意後才 merge 回 main；不直接在 main 上實作。
- 換關一律**重新載入頁面**（不在同一頁拆掉重建場景）；載入存檔也一樣，因此載入後 undo 歷史清空。
- 第 1 關除了後街北移 0.8 之外，外觀與行為要和 P1 開工前一致（回歸基準）。
- `.claude/`、`output/` 不 commit。
- Python 一律用 repo 根目錄的 `.venv`（`.\.venv\Scripts\python.exe`，不 commit）；只用來起站與跑一次性腳本，不裝套件。

## 指揮流程入口

被指定為指揮者（派工給 agy／ChatGPT／Muse）時，派工前一定要先做完 `docs/others/conductor-handbook.md` §2.0 開工前 gate：

1. 文件讀清楚：本檔 → handbook §1、§2、§5、§7 與所選 worker 段落 → 當前 Phase 三份文件裡該 Subphase 的所有對應段 → 該 Subphase 實作紀錄（若有）。不可只讀本檔就派工。
2. 契約疑點由指揮者自己裁定，寫進 step 檔；只有改變玩法意圖或推翻已拍板決定的才問使用者。
3. 從最新 main 開 Subphase 分支，起始 commit 與分支名寫進實作紀錄。

接手進行中的 Subphase 照 handbook §7。

- 新蓋的建築不擋車。
- 祝福的效果重新整理後不保留；祝福收集紀錄與投幣次數會保存。
- A2 調整初始化順序後，外圍 9 棵隨機樹的預設位置與舊基準不同；不影響功能或存檔，列為可修可不修。
- 部署時本檔與 `docs/` 也會一起被放上網站（無害）。
- 第 2 關：鐵軌延伸到地圖外供火車進出，相機拉遠平移時看得到地圖外的軌道；鐵道南側目前是空草地；車廂只有 Kenney 木材車與貨箱車，客運看起來像貨車；行人可能在平交道以外的地方跨過鐵軌；標頭文字「點噴水池可以許願」在沒有許願的關卡仍顯示；目的地建築被搬到找不到路時通勤客直接消失。
