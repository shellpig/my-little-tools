## 指揮者裁定

1. **置中**：`.ops-panel` 在桌面寬度時固定在畫面正中央（水平、垂直都置中），不再貼左邊。做法：`left: 50%; top: 50%; transform: translate(-50%, -50%)`，寬高由 `width`／`height` 決定，內容超出時面板內捲動（沿用 `overflow: auto`）。要覆蓋 `.add-panel` 的 `left`／`top`／`max-height`。
2. **預設大小**：寬 `min(760px, 100vw − 32px)`、高 `min(720px, 100vh − 32px)`。
3. **拖拉調整**：三個把手——右邊緣（只改寬）、下邊緣（只改高）、右下角（寬高都改）。因為面板置中，拖拉時以中心為基準對稱縮放：新寬 = 2 × |滑鼠 x − 面板中心 x|，新高同理，讓把手跟著滑鼠走。用 pointer events + `setPointerCapture`。把手的游標分別是 `ew-resize`、`ns-resize`、`nwse-resize`；右下角畫一個小斜線記號，邊緣把手平常看不見（寬約 8px 的透明區）。
4. **限制**：最小寬 420、最小高 320；最大寬 `innerWidth − 32`、最大高 `innerHeight − 32`（四邊至少留 16px，拉不出去）。視窗縮小時（`resize` 事件）把目前寬高夾回這個範圍。
5. **記住大小**：放開滑鼠時存 `localStorage['small-town:ops-size']`（`{"w":…,"h":…}` 字串），開頁時讀回並夾在範圍內；讀寫照既有 try/catch 寫法。屬於偏好，不進存檔。
6. **手機寬度**：`@media (max-width: 600px)` 維持現在的全寬排法（`left: 12px; right: 12px; top: 276px; width: auto`），不置中、把手隱藏、不套用存下來的大小（inline style 要能被清掉，或只在寬螢幕時才寫 inline style）。
7. 面板裡的內容排版不改（火車、公車、小鎮分頁照舊），只是容器變大。
8. 第 1 關沒有經營面板，不受影響。

## 驗收

- `node --check main.js`。
- 瀏覽器 1440×900（第 2 關）：開「經營」面板在畫面正中央，預設 760×720；拖右下角把手放大縮小，面板保持置中、把手跟著滑鼠；拖到最大四邊各留 16px；拖到最小停在 420×320；重新整理後大小保留；把視窗縮小到 900×600，面板夾回範圍內。
- 375 寬：面板維持原本全寬排法、看不到把手。
- 第 1 關主控台無錯誤。
