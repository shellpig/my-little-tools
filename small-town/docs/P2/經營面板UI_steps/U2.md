# 經營面板 UI / U2 — 購買火車：一行一種、名稱旁放車頭小圖

## 派工

- 日期：2026-10-13；worker：agy / Gemini 3.8 Flash (High)。
- 起始：`feat/small-town-ops-ui` @ `708bf09`。
- 使用者需求：購買火車在名稱旁放火車小圖；每一行放一種火車。
- 範圍：
  - `main.js`：`setupOpsPanel()` 裡的 `renderBuyButtons()`。
  - `index.html`：`#ops-buy-buttons` 的容器 class 與少量 CSS。
- 讀取範圍：main.js `renderBuyButtons()`、`renderFleetList()`（看車隊卡片既有的說明文字寫法）；atrain.js `TRAIN_TYPES`（`name`、`units`、`speed`、`price`、`seats`、`tourism`）；index.html `#ops-buy-buttons`（~325）、`.chips`、`.fleet-card` 的 CSS；`assets/train-kit/Previews/` 只確認檔名，不改。

## 指揮者裁定

1. **一行一種**：`#ops-buy-buttons` 不再是 chips 排列，改成直向清單，五種車型各一行，順序照 `TRAIN_TYPES`。整行是一顆按鈕，點下去照舊買車（沿用現有 click 處理：`spend()`、push 車隊、`rail.addTrain()`、`saveLayout()`、`renderOpsPanel()`），不改買車邏輯。
2. **小圖**：每行左邊放車頭預覽圖 `assets/train-kit/Previews/${tdef.units[0]}.png`（64×64 PNG），顯示 40×40、`object-fit: contain`、`alt=""`。不另做圖、不用 3D 截圖。
3. **文字**：圖右邊兩行——第一行車名（粗體）；第二行小字、`var(--dim)`：`速 ${speed}× · 限 ${seats} 人 · ${price} 萬`，有 `tourism` 時再加 ` · 觀光 ×${tourism}`。最右邊放「＋購買」字樣（`var(--accent)`）。沿用車隊卡片「速／限」的用詞。
4. **樣式**：每行像 `.fleet-card` 的外框與背景，hover 時背景稍亮；行與行間距 6px。新 CSS 只加必要幾條，class 名用 `ops-buy-*`。
5. 不改「車隊清單」卡片，也不在車隊卡片加小圖（使用者只要求購買區）。
6. 第 1 關沒有經營面板，不受影響。

## 驗收

- `node --check main.js`。
- 瀏覽器（第 2 關）：「購買新車」五行，每行有車頭小圖、車名、速度／載客／價格（復古客車多「觀光 ×1.5」）；點「都會電車」那行：資金扣 1,500 萬、車隊多一台；圖片沒有 404。
- 第 1 關主控台無錯誤。
