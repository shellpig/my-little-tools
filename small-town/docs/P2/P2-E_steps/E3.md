## 指揮者裁定的契約疑點

1. **只在有鐵道的關卡**：`rail` 為 null（第 1 關）時不建 AudioContext、按鈕維持 `hidden`、`frame()` 裡不呼叫。
2. **何時響**：`!muted && speed > 0` 且有任一 `rail.crossings` 的 `closed` 為真、而且 `camera.position` 到該平交道 `(c.x, 0, c.z)` 的距離 < 40。暫停時不響。60× 時照 `closed` 狀態響，不特別處理。
3. **聲音**：WebAudio 合成，不載音檔。兩個方波 oscillator（750 Hz、600 Hz）各接一個 GainNode，再接主音量 GainNode（0.04，預設音量小）→ destination。響的時候每 0.35 秒（用 `frame()` 的真實 `dt` 累計，不受倍速影響）交替把其中一個的 gain 設 1、另一個設 0；不響時兩個都 0。改 gain 用 `setTargetAtTime(v, ctx.currentTime, 0.01)` 避免爆音。oscillator 建一次、一直跑，不反覆 start/stop。
4. **AudioContext 建立時機**：瀏覽器規定要使用者手勢，第一次 `pointerdown` 或 `keydown`（`{ once: true }`）時才建；建立前 `updateBell()` 直接 return。
5. **靜音開關**：`.title` 裡、`#money` 後面加 `<button id="mute" ...>`，顯示 🔔（有聲）／🔕（靜音），`title` 寫「平交道鈴聲」。`.title` 是 `pointer-events: none`，按鈕本身要 `pointer-events: auto`。點擊切換、`blur()`。存 `localStorage['small-town:muted']`＝`'1'`／`'0'`，預設不靜音；讀寫照既有 try/catch 寫法。不進存檔。
6. 新函式：`updateBell(dt)`（frame 呼叫）、建立音訊的函式、切換靜音的處理；不要多。
