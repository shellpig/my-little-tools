## 指揮者裁定的契約疑點

1. **點選**：pointerup 裡，人／貓／噴水池、車站都沒打中時，對 `rail.fleet` 每台車 `consist.units` 中 `obj.visible` 的 `obj` 做遞迴 raycast，打中就 `followTrain(那台車的 units)`。只在 `LEVEL.atrain && rail`；編輯模式、散步模式不觸發（pointerup 既有的 `editing` return 沿用，另加 `player.active` 判斷）。
2. **跟車**：記下進入前的 `camera.position`、`controls.target`，`controls.enabled = false`。每幀：車頭＝`units[0].obj`；目標點＝車頭位置 y + 0.3；行進方向用 `obj.rotation.y`（rail.js 以 `atan2(tx, tz)` 設定，前方＝`(sin, 0, cos)`）；鏡頭理想位置＝車頭 − 前方 × 2.6、y + 1.4；`camera.position.lerp(理想, 1 - Math.exp(-4 * dt))`，`controls.target` 同樣 lerp 到目標點。
3. **結束**：按 Esc、或車頭 `obj.visible` 變 false（開出地圖）時，鏡頭回到進入前的位置與 target，`controls.enabled = true`。進編輯模式或散步模式時也先結束跟車。
4. Esc 在既有 keydown 處理裡已有用途（衣櫃、編輯）；跟車中按 Esc 只結束跟車，不觸發其他動作。
5. 新函式：`followTrain(units)`、`stopFollow()`、`updateFollow(dt)`；狀態一個模組層變數。不要多。
