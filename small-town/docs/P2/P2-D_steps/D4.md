## 指揮者裁定的契約疑點

1. **`shopCount()`**：沒被刪除的 `shop:<名稱>`（關卡 `SHOPS`，不含 `CIVIC`）＋ `add.type === 'shop'`（玩家新增與自動長出）＋ `add.kind === 'shop'` 的設施；放置中的預覽不算。設施商店的收入公式維持 P2-C（只有設施商店收錢、用總人口），本步不改 `settle()`。
2. **商店名額**：當天名額 ≥ 1 且 `住宅數 / shopCount() > 12`（`shopCount()` 為 0 視為成立）時，第 1 個名額先試長商店：從評過分的合格地塊中只看分數 ≥ 7、且「同側 3 塊地以內沒有商店」的地塊，以分數加權抽一塊。沒有符合的地塊，這個名額改長住宅。
3. **同側 3 塊地以內**：同一條臨街線（同馬路格列、同 `side`）上，沿臨街方向距離 ≤ 3.0、且位在同一側（垂直臨街方向距離地塊中心 ≤ 1.0）的範圍內，沒有任何商店（第 1 條算進去的那些）的 pivot。
4. **自動商店**：`{ type: 'shop', model: 從 ['building-a', 'building-c', 'building-h'] 隨機, name: SHOP_NAMES 隨機, theme: SHOP_THEMES 隨機索引, wall: -1, auto: true, lot, born }`，用 `buildAdded()` 建（招牌、遮雨棚沿用既有 `decorateShop`）。`SHOP_NAMES` 放在 atrain.js，12 個左右的台式小店名（例：早餐店、豆花、文具行、雜貨店、手搖飲、麵店、書店、花店、洗衣店、水果行、五金行、照相館）。不受「離車站 15 格」影響。
5. **`FACILITIES.smallApartment`**：`{ name: '小公寓', group: 'earn', pack: 'commercial', models: ['building-m'], scale: 0.75, price: 0, pop: 15, daily: 0, buyable: false }`（`price: 0` 讓刪除退款為 0，不出現 NaN）（building-m 縮 0.75 後約 0.93 × 0.93，和透天同大小）。設施分頁略過 `buyable === false` 的項目。小公寓接路時人口 +15（沿用 `population()` 的設施分支）；住宅數計入（D3 第 6 條已含）。
6. **公寓升級**：每次結算在長新房子之前做，最多 1 棟。候選 = 沒被刪除、`add.auto`、`add.type === 'house'`、`day − add.born >= 5` 的透天，且（pivot 離車站 ≤ 12 格，或 pivot 半徑 6 格內有 ≥ 3 間商店——商店照第 1 條，以 pivot 距離算）。從候選中隨機挑一棟，檢查空間：小公寓建好後，前緣對齊原住宅的門面、同旋轉（沿用 `buildOnLot()` 的放法，地塊由原住宅的 `add.lot` 還原，或直接用原住宅的門口位置與朝向），用它的實際 solid 查是否碰到 `solids`（**排除原住宅自己的 solid 與小公寓自己的**）、`sidewalkRects()`、`tiles` 格、`railCells` 格；碰到就 `discard()` 小公寓、今天不升級（不再試別棟）。通過：原住宅 `applyState(..., removed: true)`，新建 `{ type: 'facility', kind: 'smallApartment', model: 'building-m', auto: true, lot: 原 lot, born: 原 born }`，id = 原 id + `'-up'`。不進 undo 歷史。
7. **冷卻**：玩家刪除一棟 `add.auto` 的房子（透天、別墅、商店、小公寓）時，`growth.cooldown[add.lot] = p2State.day + 7`。undo 把它救回來時不清冷卻（簡化，冷卻到期自然解除）。D3 的檢查是 `day <= cooldown` 就不長，所以刪除當天算第 0 天，第 8 天起可以再長。
8. **通知**：當天長出的商店與住宅合計 N，照 D3 的「新住宅落成 ×N」；升級不跳通知。

## 驗收

- `node --check` 所有改動 JS。
- 設施分頁沒有小公寓。
- 把住宅數 ÷ 商店數拉到 > 12：隔天先長 1 間商店，分數 ≥ 7，同側 3 塊地內沒有別的商店。
- 公寓升級：滿 5 天、在車站 12 格內的自動透天升級成小公寓（人口 +15−4、大小與透天相同），每天最多 1 棟；別墅不升級；刻意擺一棟鄰屋擋住，該棟不升級。
- 刪除一棟自動房子：7 天內該地塊不長，第 8 天起可長。
