## 指揮者裁定的契約疑點

1. **地塊列舉**：對每個 `tiles` 裡的馬路格 (i, j)，每個「沒有接馬路、也不是地圖邊緣開口」的側邊（與 `sidewalkRects()` 判斷人行道的條件相同）都是一條臨街線。門面在離馬路格中心 `FRONTAGE` 處，門面朝路。沿臨街方向，地塊中心取世界座標為**整數**（每 1.0 一個）且落在該格範圍 `[格中心 − CELL/2, 格中心 + CELL/2)` 的位置，所以每個側邊 1～2 塊。`lotKey = "<i>,<j>,<side>,<k>"`，`side` 用既有的 `NORTH`／`SOUTH`／`EAST`／`WEST` 常數值，`k` 是那個整數座標。
2. **地塊方框**：透天 1.0（臨街寬）× 1.2（深），別墅 1.5 × 1.3（四款別墅實測最大 1.45 × 1.18）；前緣貼齊 `FRONTAGE`。方框四邊內縮 0.02 後檢查。
3. **不能長**（任一成立就跳過）：
   - 方框碰到任何 `sidewalkRects()` 矩形；
   - 方框碰到任何 `tiles` 格（馬路或人行道，整格 CELL × CELL）或 `railCells` 格；
   - 方框碰到 `solids`（建築、車站與月台、設施）；
   - 方框不在「地圖範圍往內縮 1 格」之內（地圖範圍 = `LEVEL.bounds` 各格的外緣）；
   - 方框內有 `posts`，而那根 post 不屬於關卡預設的樹（id `tree:N`）——玩家種的樹、路燈都會擋；
   - `day <= growth.cooldown[lotKey]`。
   關卡預設的樹在方框內時不擋，蓋下去時把它們 `applyState(..., removed: true)` 清掉（照既有 `removed` 存檔）。
4. **抽樣與評分**：每次結算列出全部地塊、洗牌，依序做第 3 條檢查（用透天方框），直到有 50 塊通過或列完；這些地塊用 `lotScore()` 評分。`ctx`：`cell = CELL`；`station` = 車站 editable（id `'station'`）的 pivot 位置；`stops` = 這次結算的停站班次數（`dailyCounts.stops.length`，在清零之前讀）；`busCells` = `p2State.buses.length > 0 && busRoute ? new Set(busRoute) : null`；`facilities` = 已接路（`facilityLinked`）、沒被刪除、不是放置中、表裡有 `growth` 的設施 `{ x, z, radius, growth }`。`lot.neighbour`：地塊方框沿臨街方向兩側各延伸 1.0 後碰到任何 `solids`（不含地塊自己）。
5. **挑選**：分數 ≥ `GROWTH_MIN_SCORE` 的才合格；以分數為權重抽籤，不放回，抽到當天名額為止。每抽中一塊，把它的方框加進當天的「已佔用」清單，後面抽到與它重疊的就作廢再抽。名額 = `GROWTH_SPEEDS[growth.speed]`；`growth.on` 為 false 時整個不做。
6. **住宅上限**：住宅數 = 沒被刪除的 `home:N` ＋ `add.type` 為 `house`／`villa` ＋ `add.kind === 'smallApartment'` 的設施（D4 才會出現）。名額 = `min(名額, 300 − 住宅數)`，≤ 0 就不長。剩下的名額作廢、不延後。
7. **長什麼**：地塊中心離車站 ≤ 15 格（`15 * CELL`）長透天：`{ type: 'house', model: 從 ['building-b', 'building-d', 'building-f', 'building-g'] 隨機（寬 ≤ 0.97、深 ≤ 1.03；building-e 寬 1.64 不用）, wall: 從 -1 到 WALLS.length - 2 隨機 }`；否則長別墅：`{ type: 'villa', model: 從 ['building-type-a', 'building-type-c', 'building-type-e', 'building-type-g'] 隨機, wall: VILLA_WALLS 隨機索引, roof: VILLA_ROOFS 隨機索引 }`。別墅要用別墅方框重新做第 3 條檢查，不過就作廢。另加 `auto: true`、`lot: lotKey`、`born: day`。
8. **建造**：`buildAdded('grow:<day>-<n>', add)`，pivot 位置 = 地塊中心、旋轉讓 +z（模型正面）朝路（北側地塊門面朝南 = rot 0，依此類推，沿用 `applyState`）。建好後用實際 solid 再查一次重疊（排除自己），重疊就 `discard()`。不進 undo 歷史。
9. **一次重建找路**：當天所有房子建完（`await Promise.all`）後呼叫一次 `settleTown()`，再 `saveLayout()`。用 `performance.now()` 量 `settleTown()` 的時間（驗證用，不留 console.log）。
10. **長出動畫**：新房子的 pivot `scale.y` 從 0 到 1，0.6 秒（現實時間），在 main loop 推進；`skipModeActive` 時直接設 1。
11. **通知**：長出 N ≥ 1 棟時 `showToast('新住宅落成 ×N')`。點通知時鏡頭移到第一棟：`controls.target` 移到它的位置，`camera.position` 平移同樣的位移。通知消失後點擊不再作用。沒長就不跳。
12. **非同步**：`growTown()` 是 async，由 `advanceClock()` 的結算段在 `settle()` 之後、清零 `dailyCounts` 之前讀好 `stops` 後呼叫（不 await）。上一天的成長還沒建完時，這次結算略過成長。
13. **第 1 關**：`LEVEL.atrain` 為 false 不做任何事。
