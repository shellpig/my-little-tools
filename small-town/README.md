# 小鎮

使用 Three.js 製作的迷你小鎮網頁。可以看居民與交通、散步找貓、編輯街道建築，也可以在火車小鎮管理班表與收支。

**[直接玩線上版](https://small-town.wetwareassembly.com/)**，不需要安裝。

## 目前內容

- 第 1 關「公園小鎮」：居民作息、找貓、噴水池許願與散步。
- 第 2 關「火車小鎮」：鐵道、火車班表、公車、公共設施、每日收支與住宅成長。
- 晝夜、天氣、音樂、畫質切換、建築與道路編輯、10 格存檔與佈局 JSON 匯出／匯入。

## 本機啟動

需要支援 WebGL 與 JavaScript modules 的現代瀏覽器，以及能從命令列執行的 Python 3。頁面透過 jsDelivr 載入 Three.js，需要網路；素材放在 repo 內。不需要 Node.js、npm 或建置步驟。

Windows：

1. 取得 repo 後，進入 `small-town`。
2. 雙擊 `start.bat`，會啟動 Python 靜態伺服器並用預設瀏覽器開啟 `http://localhost:8766/`。
3. 保留伺服器視窗。結束時關閉該視窗，或執行 `stop.bat`。

若腳本找不到 Python，先安裝 Python 3，確認 `python` 或 `py` 可用，再重試。不要直接雙擊 `index.html`；`file://` 會影響模組與模型載入。

其他平台也可在 `small-town` 目錄執行：

```sh
python3 -m http.server 8766 --bind 127.0.0.1
```

再手動開啟 `http://localhost:8766/`，結束時按 Ctrl+C。Windows 若手動起站，可用 `py -3` 取代 `python3`。

## 基本操作

| 操作 | 用途 |
|---|---|
| 左鍵拖曳／右鍵拖曳／滾輪 | 平移／旋轉／縮放鏡頭 |
| 觸控單指拖曳／雙指縮放、旋轉 | 操作俯瞰鏡頭 |
| 點人物、貓、噴水池 | 對話、找貓、許願 |
| 空白鍵 | 暫停／繼續時間；散步模式中改為跳躍 |
| `P` | 進入／離開散步模式 |
| WASD／Shift／`E`／`C` | 散步時移動／跑步／互動／換裝 |
| `B` | 進入／離開編輯模式 |
| `R`／Delete／Ctrl+Z | 編輯時旋轉／刪除／復原 |
| 「關卡與存檔」 | 換關卡、儲存與讀取進度、匯出／匯入佈局 |
| 第 2 關「經營」 | 管理車隊、班表與小鎮收支 |

觸控裝置的散步模式有畫面搖桿與動作按鈕；火車班表拖放目前只支援滑鼠。

## 存檔與備份

進度、10 格存檔與偏好保存在目前瀏覽器的 `localStorage`，不會上傳，也不會自動跨裝置同步。清除網站資料可能讓存檔消失；無痕模式結束後也可能不保留。

線上版與本機版的存檔各自獨立；`localhost`、`127.0.0.1` 或不同連接埠也屬於不同的網站儲存空間。

在「關卡與存檔」可匯出目前關卡的佈局為 `small-town-layout.json`，並在另一個瀏覽器匯入。這是**目前關卡佈局**，不是全部存檔、找貓紀錄或個人偏好的完整備份。匯入會切換關卡並取代目前進度，操作前會要求確認。

## 疑難排解

| 狀況 | 處理 |
|---|---|
| 頁面空白或模型沒出現 | 確認是用 HTTP 網址開啟、伺服器仍在執行，且能連線 jsDelivr |
| 埠號 8766 已被占用 | 若是之前啟動的小鎮，先執行 `stop.bat`；否則手動選其他未占用埠號起站，再開對應網址 |
| 畫面很慢 | 先把畫質改成「低」或「中」，並確認瀏覽器可使用硬體加速 |
| 換瀏覽器或網址後存檔不見 | 回到原本的瀏覽器與完整網址；需要搬移佈局時用匯出／匯入 |
